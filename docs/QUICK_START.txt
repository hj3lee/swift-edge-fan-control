Acer Swift Edge SFE16-43 Fan Control

Tested: SFE16-43 / Ray_PEU / BIOS V1.71 / Windows 11 x64.
No model/board/BIOS allowlist is enforced. Other hardware is unverified.
Install official PawnIO once: https://pawnio.eu/
Extract the complete ZIP. Run SwiftEdgeFanControl.exe and accept UAC.
No separate .NET SDK is required.

Choose Fan curve mode, fixed level 1-7, or Manufacturer default.
Levels are EC steps, not exact RPM targets. Curve settings edits the curve.
CPU temperature and fan RPM are sampled every 10 seconds.
At a sampled CPU temperature >=90 C, control returns to manufacturer auto.
Persistent communication errors and external level changes also trigger auto.
The independent watchdog attempts recovery after a stalled/crashed controller.
Long-term reliability is not established; communication timeouts can occur.

X hides to the tray. Exit restores manufacturer automatic control.
Run at Windows login is optional. Uncheck it before removing the app.
Settings and logs: %LOCALAPPDATA%\SwiftEdgeFanControl
English is the default; six interface languages are available.
